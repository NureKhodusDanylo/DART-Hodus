# DART-Hodus — лабораторні роботи з дисципліни «Програмування мовою Dart»

Варіант 10 — «Планувальник завдань» (номер у списку збірної групи 25).
Наскрізний проєкт `task_planner`: кожна лабораторна робота — окрема папка з повним
проєктом Dart свого етапу. Історія розвитку збережена в Git, підсумковий стан кожної
роботи позначено тегом `lab1`…`lab4`.

| Папка | Робота | Зміст | Тести |
|---|---|---|---|
| [`lab1/`](lab1/) | ЛР1. Функції, колекції, рядки й дати | розбір, перевірка, конвеєри, групування на функціях і записах | 8 |
| [`lab2/`](lab2/) | ЛР2. Класи, ієрархії, домішки, узагальнення | клас `Task`, `sealed TaskStatus`, `enum Priority`, домішка `Scheduled`, `Repository<T>` | 11 |
| [`lab3/`](lab3/) | ЛР3. Асинхронність: Future, Stream, ізоляти | `AsyncRepository`, події на `StreamController`, `Isolate.run` | 22 |
| [`lab4/`](lab4/) | ЛР4. Модульність, файли, HTTP і JSON, супровід | CLI на `args`, JSON-файл, REST API, HTTP-сервіс на `shelf` | 38 |

Опис рішень кожної роботи — у `README.md` її папки.

## Запуск

```bash
cd lab4
dart pub get
dart analyze
dart test
dart run bin/task_planner.dart --help
```

Для інших робіт — так само в їхній папці (`dart run bin/task_planner.dart`).
